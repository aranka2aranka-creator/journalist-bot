# ربات امتیازدهی خبرنگاران (بله)

این پروژه شامل دو بخش است:

1. **ربات بله** (`bot.py`) — خبرنگاران فایل PDF/عکسِ خبر را برای ربات می‌فرستند و به ترتیب
   نام روزنامه، نام خودشان، تیتر و تاریخ را وارد می‌کنند. ربات این‌ها را در دیتابیس ذخیره
   و یک امتیاز اولیه ثابت می‌دهد.
2. **پنل مدیریت وب** (`admin_panel/app.py`) — شما هر وقت خواستید وارد می‌شوید، خبرهای
   ثبت‌شده را می‌بینید، مشخص می‌کنید کدام صفحه اول بوده و امتیاز نهایی هر خبر را اصلاح
   می‌کنید. جمع امتیاز هر روزنامه هم بالای صفحه نمایش داده می‌شود و خروجی اکسل هم دارد.

هر دو از یک دیتابیس مشترک (PostgreSQL) استفاده می‌کنند.

---

## قدم ۱ — ساخت ربات در بله

1. در اپلیکیشن بله، ربات **BotFather** (یا معادل آن در بله) را پیدا کنید.
2. دستور ساخت ربات جدید را بزنید و یک نام برای ربات انتخاب کنید.
3. توکنی که بله به شما می‌دهد را جایی امن کپی کنید؛ همین را در مرحله بعد نیاز داریم.

## قدم ۲ — ساخت پروژه در Railway

1. وارد [railway.app](https://railway.app) شوید و یک حساب بسازید (اگر ندارید).
2. یک پروژه جدید بسازید و کد این پوشه را در یک ریپازیتوری گیت‌هاب قرار دهید، سپس
   "Deploy from GitHub repo" را انتخاب کنید.
   (اگر نمی‌خواهید از گیت‌هاب استفاده کنید، Railway CLI هم گزینه‌ی دیگری است.)
3. داخل همان پروژه، روی "New" بزنید و **PostgreSQL** را اضافه کنید. Railway به‌صورت خودکار
   متغیر `DATABASE_URL` را می‌سازد و آن را در اختیار سرویس‌های دیگر همان پروژه قرار می‌دهد.

## قدم ۳ — تنظیم دو سرویس (ربات و پنل وب)

چون یک `Procfile` با دو process type (`worker` و `web`) داریم، بهتر است از همین یک
ریپازیتوری، **دو سرویس جدا** در Railway بسازید (هر دو به همان ریپازیتوری وصل باشند):

- سرویس اول: Start Command را روی `python bot.py` بگذارید (این همان ربات بله است).
- سرویس دوم: Start Command را روی `python admin_panel/app.py` بگذارید (این پنل وب است).
  Railway به این سرویس خودش یک آدرس اینترنتی می‌دهد که از همان‌جا پنل را باز می‌کنید.

## قدم ۴ — متغیرهای محیطی (Environment Variables)

در هر دو سرویس (چون هر دو باید به دیتابیس وصل شوند)، این متغیرها را طبق فایل
`.env.example` تنظیم کنید:

| متغیر | برای چیست |
|---|---|
| `BALE_BOT_TOKEN` | توکنی که در قدم ۱ از بله گرفتید (فقط لازم سرویس ربات است) |
| `DATABASE_URL` | Railway خودش این را می‌سازد؛ کافی است در تنظیمات سرویس، "Reference" به سرویس PostgreSQL بدهید |
| `ADMIN_USERNAME` | نام کاربری ورود به پنل (فقط لازم سرویس پنل وب) |
| `ADMIN_PASSWORD` | رمز عبور ورود به پنل — حتماً یک رمز قوی بگذارید |
| `ADMIN_SECRET_KEY` | یک رشته تصادفی طولانی، فقط برای امنیت نشست پنل |

## قدم ۵ — اجرا

بعد از تنظیم متغیرها، Railway به‌صورت خودکار هر دو سرویس را deploy و اجرا می‌کند.
- برای تست ربات: در بله به ربات‌تان پیام `/start` بدهید.
- برای پنل: آدرسی که Railway به سرویس دوم داده را باز کنید و با `ADMIN_USERNAME` و
  `ADMIN_PASSWORD` وارد شوید.

## اجرای محلی (اختیاری، برای تست قبل از آپلود)

```bash
pip install -r requirements.txt
cp .env.example .env   # و مقادیر را پر کنید
export $(cat .env | xargs)   # در لینوکس/مک

# اجرای ربات
python bot.py

# اجرای پنل (در یک ترمینال دیگر)
python admin_panel/app.py
```

اگر `DATABASE_URL` را خالی بگذارید، پروژه به‌صورت خودکار از یک فایل SQLite محلی
(`local_dev.db`) استفاده می‌کند تا بدون نیاز به PostgreSQL هم بتوانید تست کنید.

## نکات مهم درباره امتیازدهی

- هر ارسالِ کامل (فایل + همه فیلدها)، به‌صورت خودکار یک امتیاز پایه می‌گیرد
  (قابل تغییر در `scoring.py`، متغیر `BASE_SUBMISSION_SCORE`).
- تشخیص «صفحه اول بودن» و امتیاز نهایی هر خبر **همیشه دستی** و از طریق پنل انجام می‌شود،
  تا خبرنگاران نتوانند خودشان ادعای دروغ درباره صفحه اول بودن ثبت کنند.
- در پنل، ستون «امتیاز نهایی» تا وقتی خالی باشد، در محاسبه جمع امتیاز هر روزنامه همان
  امتیاز اولیه در نظر گرفته می‌شود؛ به‌محض این‌که عددی در آن بگذارید و ذخیره کنید،
  همان عدد ملاک محاسبه پرداخت می‌شود.

## توسعه‌های بعدی که ساده اضافه می‌شوند

- نمایش خود فایل PDF/عکس در پنل (نیاز به یک روت پراکسی برای دانلود فایل از بله دارد)
- ارسال خودکار گزارش اکسل هفتگی به یک چت بله
- محدود کردن ثبت به لیستی از خبرنگاران از پیش تاییدشده
